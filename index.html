📱 iPhone 全系包装规律

全系不赠送充电头、不赠送耳机、不赠送卡针（美版等 eSIM 机型）及 Apple 贴纸。 盒内仅含主机与 1 米 USB-C 编织充电线。若需满速快充，建议自备 30W–60W PD 充电头（官方或认证第三方）。

平板 iPad 全系包装规律

北美/国行/亚太版本盒内均标配 20W USB-C 充电头 + 1 米 USB-C 充电线（欧盟/英国版因法规不含充电头）。选配纳米纹理玻璃版 iPad Pro / mini 额外附赠价值 ¥145 的原装抛光布。

💻 MacBook 全系包装规律

全系附赠原装电源适配器与充电线：MacBook Neo 标配 20W 头 + 1.5m USB-C 线；MacBook Air 标配 40W 动态电源适配器(最高60W) + 2m MagSafe 3 线；MacBook Pro 标配 70W/96W/140W 适配器 + MagSafe 3 线。

Quick Start · 电脑本地与云端运行指南 Python 3.9+
方式 1：在你电脑上本地运行爬虫更新（推荐）

解压我为你打包好的 apple_realtime_sync_suite.zip 后，在终端执行：

pip install requests beautifulsoup4
python3 apple_scraper.py --output data/models.json
python3 -m http.server 8080

随后浏览器访问 http://localhost:8080，前端就会自动加载爬虫刚生成的 data/models.json！

方式 2：部署到 GitHub 开启全自动定时更新
  1. 将解压后的文件夹上传至你的 GitHub 仓库。
  2. 仓库内的 .github/workflows/update_models.yml 会自动生效，每天定时抓取 Apple 官网并更新 data/models.json。
  3. 开启仓库的 GitHub Pages，即可获得一个永久免费且每日自动同步 Apple 官网数据的在线对比网站。
